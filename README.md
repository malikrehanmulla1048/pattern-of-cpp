# Pattern of C++ 🚀

A comprehensive collection of C++ programs, data structures, algorithms, sorting techniques, advanced problem-solving questions, and pattern-printing logic. This repository serves as a personal archive for practicing core computer science concepts and coding interview problems.

---

## 📂 Repository Structure & Topics

### 1. Data Structures & Trees
* **[binary_search_tree.cpp](https://github.com/malikrehanmulla1048/pattern-of-cpp/blob/main/binary_search_tree.cpp)** - Implementation of Binary Search Trees with insertion, traversal, and advanced search operations.
* **[binarytree.cpp](https://github.com/malikrehanmulla1048/pattern-of-cpp/blob/main/binarytree.cpp)** - Basic Binary Tree operations and structural traversals.
* **[sumTree.cpp](https://github.com/malikrehanmulla1048/pattern-of-cpp/blob/main/sumTree.cpp)** - Checking and converting trees into Sum Trees.
* **[queue.cpp](https://github.com/malikrehanmulla1048/pattern-of-cpp/blob/main/queue.cpp)** - Queue data structure implementation.
* **[circularQueue.cpp](https://github.com/malikrehanmulla1048/pattern-of-cpp/blob/main/circularQueue.cpp)** - Circular Queue implementation.

### 2. Algorithms & Problem Solving
* **[1563_stone_game_V.cpp](https://github.com/malikrehanmulla1048/pattern-of-cpp/blob/main/1563_stone_game_V.cpp)** - Dynamic programming solution for LeetCode 1563 (Stone Game V).
* **[Aggresive.cpp](https://github.com/malikrehanmulla1048/pattern-of-cpp/blob/main/Aggresive.cpp)** - Aggressive Cows problem using Binary Search on Answer.

* **[sudoku.cpp](https://github.com/malikrehanmulla1048/pattern-of-cpp/blob/main/sudoku.cpp)** - Sudoku solver using Backtracking.
* **[combinational_sum.cpp](https://github.com/malikrehanmulla1048/pattern-of-cpp/blob/main/combinational_sum.cpp)** - Finding all unique combinations that sum up to a target.
* **[moore_s_voting.cpp](https://github.com/malikrehanmulla1048/pattern-of-cpp/blob/main/moore_s_voting.cpp)** - Finding the majority element using Moore's Voting Algorithm.
* **[most_water.cpp](https://github.com/malikrehanmulla1048/pattern-of-cpp/blob/main/most_water.cpp)** - Container with most water problem (Two-pointer approach).
* **[product_of_array_except_self.cpp](https://github.com/malikrehanmulla1048/pattern-of-cpp/blob/main/product_of_array_except_self.cpp)** - Optimal $O(n)$ solution for array product calculations.

* **[search_2d.cpp](https://github.com/malikrehanmulla1048/pattern-of-cpp/blob/main/search_2d.cpp)** - Efficient searching algorithms in 2D matrices.
* **[spiral.cpp](https://github.com/malikrehanmulla1048/pattern-of-cpp/blob/main/spiral.cpp)** - Spiral matrix traversal.
* **[singleNonDuplicaten.cpp](https://github.com/malikrehanmulla1048/pattern-of-cpp/blob/main/singleNonDuplicaten.cpp)** - Finding the single non-duplicate element in a sorted array.
* **[find_dup.cpp](https://github.com/malikrehanmulla1048/pattern-of-cpp/blob/main/find_dup.cpp)** - Duplicate detection in arrays.
